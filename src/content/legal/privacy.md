This website is a static academic profile hosted with GitHub Pages and served through Cloudflare DNS/CDN services.

The site does not use advertising trackers, embedded maps, remote web fonts, or third-party icon scripts. It uses [GoatCounter](https://www.goatcounter.com) for privacy-friendly aggregate visit statistics, with the analytics script hosted on this site; it sets no cookies, stores no analytics identifiers in localStorage, and does not track visitors across sites. GoatCounter receives page paths, referrers, browser and screen sizes, and approximate countries inferred from IP addresses solely to summarize visits and sources; according to its [privacy information](https://www.goatcounter.com/help/privacy), it does not persist full IP addresses.

Cloudflare and GitHub may process technical request data such as IP address, browser information, requested URL, and request time as part of hosting, DNS, security, caching, and delivery operations.

Email links open the visitor's own email client. Cloudflare Email Obfuscation may be enabled for this site to reduce automated email scraping.
